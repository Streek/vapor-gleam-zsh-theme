# Product

Vapor Gleam is a dark-terminal Zsh theme inspired by Gleam branding. The prompt shows user/host, current directory, Git branch, and time with a pink, gold, lilac, and teal true-color palette and a Unicode arrow.

It can be installed through Oh My Zsh, Antidote/Zinit, or by sourcing the theme file directly. Git and a Unicode-capable font improve the optional segments and presentation.
